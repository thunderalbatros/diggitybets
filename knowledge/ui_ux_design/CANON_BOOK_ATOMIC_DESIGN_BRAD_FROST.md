# Atomic Design (Edición en Español)
*Autor: Brad Frost*  
*Archivo fuente en biblioteca:* `Atomic-Design-Brad-Frost-Spanish.pdf`  
*Categoría:* `UI_UX_y_Ergonomia`

## 🧠 Tesis Central y Modelo Teórico
Metodología fundacional para crear sistemas de diseño de interfaces escalables y coherentes. Divide la UI en cinco etapas jerárquicas que van desde las partículas más diminutas (colores, espaciados, inputs) hasta las vistas completas de producción.

## ⚙️ Principios Clave y Mecánicas
- **Átomos (Tokens)**
- **Moléculas (Componentes Simples)**
- **Organismos (Módulos Complejos)**
- **Plantillas (Layouts)**
- **Páginas (Vistas Finales)**

## 🚀 Aplicación en Arquitectura Web & HuntHub
Estructuración modular de HuntHub Web UI: tokens en src/constants/theme.ts (átomos), cards de eventos y badges de quórum (moléculas), tab de Club y Radar (organismos), ensamblados bajo la regla estricta de modularidad <150 líneas.
