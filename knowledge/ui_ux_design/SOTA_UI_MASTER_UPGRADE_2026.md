## ⚙️ 3. Pila Tecnológica Canónica de HuntHub Web

1. **Estructura y Semántica:** HTML5 semántico (`<main>`, `<nav>`, `<section>`, `<dialog>`, `aria-*`).
2. **Estilizado y Diseño:** Vanilla CSS moderno con Custom Properties (CSS variables), CSS Grid (Bento layouts), Flexbox y Container Queries.
3. **Animación y Cinemática:** Web Animations API (`element.animate()`) con curvas `cubic-bezier(0.22, 1, 0.36, 1)` y CSS Keyframes.
4. **Gráficos en Tiempo Real:** Canvas 2D y Three.js (WebGL/WebGPU) con buffers eficientes y pooling de geometrías.
5. **Audio y Síntesis Procedural:** Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`, `BiquadFilterNode`) para efectos sonoros táctiles sin cargar archivos MP3 externos.
6. **Rendimiento en Streaming (OBS):** Mantener el impacto en CPU $\le 5\%$ animando únicamente propiedades compuestas (`transform`, `opacity`).
