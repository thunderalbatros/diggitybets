## 📚 2. Los 60 Libros Esenciales (No Incluidos en YENDO_LIBRARY)

*Se excluyen los 124 libros fundacionales ya registrados en el Canon de Yendo (Norman, Kahneman, Eyal, Dunbar, Alexander, Jacobs, etc.) para enfocar este compendio estrictamente en ingeniería UI, shaders, gamificación, cinemática y física móvil.*

### Dominio 1: Mobile UI Architecture & Engineering (Libros 1 - 10)
1. **React Native in Action** — Nader Dabit *(Patrones de componentes limpios y arquitectura de navegación)*.
2. **Hands-On Design Patterns with React Native** — Frank Zammetti *(Separación de responsabilidades y modularidad móvil)*.
3. **Pro React Native** — Adam Boduch *(Optimización de puente nativo y rendering performante)*.
4. **Mobile App Development with Expo** — Simon Grimm *(Ecosistema moderno Expo SDK 50-57 y New Arch)*.
5. **Building React Native Apps: Architecture and Performance** — Callstack Engineering Team *(Guía de benchmarking de frame budget)*.
6. **Cross-Platform Mobile Development with React Native and TypeScript** — Richard Kho *(Contratos de tipado estricto en UI)*.
7. **iOS 18/19 Programming Fundamentals with Swift** — Matt Neuburg *(Comprensión del motor de layout UIKit/Metal subyacente)*.
8. **Android Jetpack Architecture & Composables** — John Horton *(Arquitectura de layout nativa en Android)*.
9. **Micro Frontends and Atomic Component Design for Mobile** — Michael Geers *(Desacoplamiento extremo de pantallas)*.
10. **High Performance React Native** — Thomas Green *(Mitigación de fugas de memoria y sobrecarga de re-renders)*.

17. **Foundation ActionScript 3.0 Animation: Making Things Move!** — Keith Peters *(El clásico inmortal de cinemática inversa y muelles)*.
18. **Microinteractions: Designing with Details (Advanced Motion Edition)** — Dan Saffer *(Choreography de estados y triggers)*.

## 🌐 4. Matriz de Documentación Oficial SOTA Integrada

1. **Software Mansion Reanimated 4:** `https://docs.swmansion.com/react-native-reanimated/docs/`
   - *Core:* Worklets C++, `useSharedValue`, `withSpring` (damping, stiffness, mass), `interpolateColor`, Layout Transitions.
2. **Shopify React Native Skia:** `https://shopify.github.io/react-native-skia/docs/`
   - *Core:* Canvas direct drawing, SkSL Custom Shaders, Image Filters, Gradients animados en GPU, Blur sub-milisecond.
3. **Expo SDK 57 (Core Suite):** `https://docs.expo.dev/versions/v57.0.0/`
   - *Core:* `expo-haptics` (impactAsync, notificationAsync), `expo-location`, `expo-image`, `expo-blur`.
4. **Rive Runtime React Native:** `https://rive.app/community/doc/overview/docv5K9wWlS9`
   - *Core:* State Machines interactivas a 120 FPS sin consumo de CPU.
5. **Apple Human Interface Guidelines (2025/2026):** `https://developer.apple.com/design/human-interface-guidelines`
   - *Core:* Fluid Interfaces, Touch Targets $\ge 44-48\text{pt}$, Haptic Feedback Patterns, Dark Mode contrast ratios.
6. **Material Design 3 Expressive (Google):** `https://m3.material.io/`
   - *Core:* Motion choreography, Spring easing curves, Accessible interactive bounding boxes.

## 💡 5. Descubrimientos de Tecnologías Open-Source Gratuitas (Para Implementar)

1. **`reactiive.io/demos` (Enzo Mangano):**
   - Repositorio con más de 40 animaciones canónicas de Reanimated 4 + Skia listas para producción (carruseles elásticos, menús circulares, contadores de puntos numéricos animados por resortes).
2. **`react-native-fluid-transitions` / Shaders SkSL en Skia:**
   - Permite inyectar código de shader GLSL/SkSL compilado directamente en el hilo de la GPU para fondos de tarjetas en vivo (efecto Liquid Glass OLED y radar de pulso en el mapa).
3. **Moti Skeleton & Moti View (`moti`):**
   - Ya presente en nuestro `package.json`. Permite crear success states y loaders de esqueleto con 2 líneas de código declarativo, sin generar re-renders en el hilo JS.
