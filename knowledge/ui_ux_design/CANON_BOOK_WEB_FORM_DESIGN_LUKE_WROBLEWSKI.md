# Web Form Design: Filling in the Blanks
*Autor: Luke Wroblewski*  
*Archivo fuente en biblioteca:* `Web-Form-Design-Luke-Wroblewski.pdf`  
*Categoría:* `UI_UX_y_Ergonomia`

## 🧠 Tesis Central y Modelo Teórico
La referencia mundial de diseño de formularios y recolección de datos. Demuestra que cada campo innecesario reduce un 15-20% la tasa de conversión. Los formularios móviles deben aprovechar chips seleccionables, valores predeterminados inteligentes y validación reactiva en tiempo real sin recargar la pantalla.

## ⚙️ Principios Clave y Mecánicas
- **Zero Keyboard Onboarding**
- **Inline Validation**
- **Smart Defaults**
- **Visual Hierarchy in Inputs**
- **Tappable Target Sizing**

## 🚀 Aplicación en Arquitectura Web & HuntHub
Arquitectura de onboarding en HuntHub Web con 0 inputs de texto libre para preferencias: selección ágil por tags táctiles de 44dp, selección rápida por categorías y login en 1-tap con biometría.
