# Animation at Work
*Autor: Rachel Nabors*  
*Archivo fuente en biblioteca:* `dokumen.pub_animation-at-work-9781937557591.pdf`

## 🧠 Tesis Central y Modelo Teórico
El movimiento en interfaces no es decoración, es infraestructura cognitiva. La animación explica de dónde vino un elemento y hacia dónde va, evitando que el cerebro gaste energía descifrando cambios abruptos en la pantalla.

## ⚙️ Principios Clave y Mecánicas
- **Functional Animation**
- **Spatial Orientation**
- **Perceptual Continuity**
- **Cognitive Bridge**

## 🚀 Aplicación Directa al ADN Yendo (Mobile, Backend & GTM)
Worklets de React Native Reanimated para sheet gestures y scroll reveals en el UI Thread a 120 FPS fijos sin bloquear JavaScript.
