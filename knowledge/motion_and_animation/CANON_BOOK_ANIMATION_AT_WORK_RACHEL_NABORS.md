# Animation at Work
*Autor: Rachel Nabors*  
*Categoría:* `Web_Animation_y_Cognitive_Design`

## 🧠 Tesis Central y Modelo Teórico
El movimiento en interfaces web no es decoración accesoria, es infraestructura cognitiva. La animación explica espacialmente de dónde vino un elemento y hacia dónde va, evitando que el cerebro gaste energía cognitiva descifrando cambios abruptos en la pantalla o en transmisiones en vivo.

## ⚙️ Principios Clave y Mecánicas
- **Functional Animation:** Movimiento con propósito explícito (orientar, confirmar, alertar).
- **Spatial Orientation:** Continuidad espacial entre estados de la aplicación web (listas que se filtran, modales que emergen).
- **Perceptual Continuity:** El usuario nunca pierde el rastro visual de los elementos clave tras una acción interactiva.
- **Cognitive Bridge:** Reducción de la carga mental al suavizar transiciones de estado complejas en tiempo real.

## 🚀 Aplicación en Arquitectura Web & HuntHub
- **Transiciones en Ruleta y Torneos:** Uso de Web Animations API (WAAPI) y CSS Transitions para animar el carrusel de premios y los cuadros del torneo a 60 FPS sin bloquear el hilo principal de JavaScript.
- **Overlays para OBS:** Animaciones fluidas basadas exclusivamente en `transform` y `opacity` con menos del 5% de uso de CPU.
