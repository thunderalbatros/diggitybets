# Provably Fair House Games Architecture

## 1. Core Commitment Scheme (HMAC-SHA256)
Every round uses three inputs:
1. `serverSeed`: 256-bit secret string generated by the server.
2. `serverSeedHash`: `SHA-256(serverSeed)` published before any bets are placed.
3. `clientSeed`: Seed chosen or randomly provided by the player.
4. `nonce`: Sequential integer representing the number of bets made with this pair.

```typescript
import { createHmac } from 'crypto';

export function generateGameHash(serverSeed: string, clientSeed: string, nonce: number): string {
  return createHmac('sha256', serverSeed)
    .update(`${clientSeed}:${nonce}`)
    .digest('hex');
}
```

## 2. Plinko Physics & Path Generation
In Plinko, a ball hits pins across $N$ rows (e.g. 8 to 16 rows).
Each pin hit represents a binary choice (0 = bounce left, 1 = bounce right):

```typescript
export function getPlinkoPath(hash: string, rows: number): { path: number[], finalBin: number } {
  const path: number[] = [];
  let finalBin = 0;
  for (let i = 0; i < rows; i++) {
    // Read 2 hex characters (1 byte)
    const byte = parseInt(hash.substr(i * 2, 2), 16);
    const direction = byte % 2; // 0 = left, 1 = right
    path.push(direction);
    finalBin += direction;
  }
  return { path, finalBin };
}
```

## 3. European Roulette (Single Zero, 0..36)
Generates an unbiased uniform integer in `0..36`:

```typescript
export function getRouletteNumber(hash: string): number {
  const hex = hash.substring(0, 8);
  const intVal = parseInt(hex, 16);
  // Rejection sampling or uniform float
  const floatVal = intVal / 0x100000000;
  return Math.floor(floatVal * 37);
}
```

## 4. Card Games (Blackjack & Hi-Lo)
Fisher-Yates deck shuffle seeded by the hash:

```typescript
export function getShuffledDeck(hash: string): number[] {
  // 52 cards: 0..51 (0..12 Spades, 13..25 Hearts, 26..38 Diamonds, 39..51 Clubs)
  const deck = Array.from({ length: 52 }, (_, i) => i);
  let hashOffset = 0;

  for (let i = deck.length - 1; i > 0; i--) {
    const chunk = hash.substr(hashOffset % (hash.length - 4), 4);
    hashOffset += 4;
    const rand = parseInt(chunk, 16) / 0x10000;
    const j = Math.floor(rand * (i + 1));
    [deck[i], deck[j]] = [deck[j], deck[i]];
  }
  return deck;
}
```

## 5. Verification Endpoint
Always provide a public client-side verification tool where players can paste their `serverSeed`, `clientSeed`, and `nonce` to verify the calculated outcome independently.
