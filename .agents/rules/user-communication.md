# Rule: User Communication

1. Language with the user: Argentine Spanish, approachable, simple, without unexplained developer jargon.
2. Code, commits, variable names, and technical identifiers: English.
3. User documentation (`GUIA_STREAMER.md`, etc.): Spanish.
4. Gate interactions:
   - Provide concise 1-page summaries with 3-bullet achievements.
   - Clear checklists for any required manual/human actions.
   - Maximum 5 questions per gate, each paired with a sensible default recommendation.
5. Honesty: If a feature, API limit, or detail cannot be verified against official documentation, state it transparently.
